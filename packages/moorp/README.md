# moorp

A local-first visual workspace for code-driven frontend design: an infinite canvas of live Page and Design frames, where code stays the source of truth.

Commands (Vue + Vite projects):

- `moorp init` creates `.visual-canvas/` with a `preview.ts` and a sample canvas.
- `moorp dev [--port <n>]` starts your Vite dev server with the canvas at `/__moorp/`.

The published `moorp@0.0.0` is a name-reservation release; this package is not published yet. See the repository README for how to run it.
